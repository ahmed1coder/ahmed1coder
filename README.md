## Selected projects

### 🛒 CenturisPOS — Retail point of sale

An Arabic-first, offline-first desktop POS built around fast barcode checkout and the realities of running a retail store. Its scope includes inventory, sales, returns, customer credit, shifts, receipt printing, and hardware-connected workflows.

**Built with:** Svelte 5, TypeScript, Tauri 2, Rust, SQLite.

### 🕒 CenturisTime — Attendance management

A bilingual desktop application for managing employee attendance from compatible network attendance devices. It brings together device synchronization, attendance records, local encrypted storage, and data backup/restore.

**Built with:** Svelte 5, TypeScript, Tauri 2, Rust, SQLite.
